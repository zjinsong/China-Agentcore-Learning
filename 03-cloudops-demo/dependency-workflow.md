# 依赖式协作

对于“查两台运行 EC2 的性能，并检查今天有没有关机操作”，正确计划是：

| 步骤 | 专家 | 能力 | 依赖 |
| --- | --- | --- | --- |
| 1 | Monitoring | 发现运行 EC2 | 无 |
| 2 | Monitoring | 查询资源指标 | 步骤 1 的实例 ID |
| 3 | CloudTrail | 查询审计事件 | 无 |

步骤 1 与 3 并行；步骤 2 等待步骤 1。一个专家可执行多个不同能力，不能因为“专家重复”拒绝合法 DAG；同一能力不应无限重复。

上游失败时，下游必须停止并明确说明“没有使用缺失的上游数据继续推测”。结果应传递结构化字段与工具状态，而不是只传一段自然语言。
